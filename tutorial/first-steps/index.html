Open, move and edit

On this page

  • Open the file
  • Two modes
  • Move around
  • Add a task
  • Change a line
  • Undo, and saving

Open the file🔗

In a terminal, go to the folder that holds the sample file and run:

tpt tutorial.taskpaper

You see the outline. At the top is the breadcrumb bar, with a house icon for the top of the file. At the bottom is the status line: it says NAVIGATE and shows the file’s path.

The ▌ bar on the left marks the focused line. Most keys act on that line.

Run tpt on its own to try a demo outline in a temporary file.

Two modes🔗

tpt has two modes, a little like vi:

  • In navigate mode every key is a command. j moves down, it doesn’t type a “j”.
  • In edit mode you type text into one line, as in any editor.

You start in navigate mode, and the status line always shows the mode.

Move around🔗

Press j to move down and k to move up, or use the arrow keys.

Press G to jump to the last line, then g g to jump back to the first. Keys written side by side like that are pressed one after the other, not together.

Ctrl+D and Ctrl+U move a page down and up.

Add a task🔗

Move to “Buy a birthday card for Mum” in the INBOX. Press o to open a new line below it, and type:

Water the plants

Added next to a task, the new line is a task too, with its dash already there. The status line now says EDIT.

Press Enter to finish this line and start the next one. Type “Take out the recycling”, then press Esc to go back to navigate mode.

Change a line🔗

To edit a line that’s already there, move to it and press Enter. The caret goes to the end. Go back to “Water the plants”, press Enter, type “ on the balcony“ and press Esc.

Undo, and saving🔗

Made a mess? Press z in navigate mode to undo, and Z to redo.

You never need to save. tpt writes the file about a second after your last change, and keeps a daily backup copy too.

To quit, press Ctrl+Q. But stay for now: the next chapter carries on in the same file.

More on editing and files is in the Reference.

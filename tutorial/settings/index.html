Settings, themes and next steps

On this page

  • Choose a theme
  • The settings window
  • Where to go next

Choose a theme🔗

Press :, type theme and press Enter for the Theme picker: Catppuccin, Tokyo Night, Nord, Gruvbox, Solarized Light and more. Move with ↓ and ↑ and the screen previews each theme. Enter keeps it; Esc goes back.

The default, Terminal Dark, uses your terminal’s colors. The others need truecolor; without it the picker says so.

The settings window🔗

Press g , for Settings. Move with j and k, and press Enter to change a setting. You can:

  • turn word wrap on, so long lines wrap instead of ending in …,
  • turn icons off, if your font draws them as boxes,
  • choose which special views the Navigator lists,
  • change how soon tpt saves after you type, and how many daily backups it keeps.

Changes apply at once and are saved to config.toml, a text file whose path the footer shows; you can edit it by hand, for example to change keys. Esc closes the window.

Where to go next🔗

You don’t need to remember every key.

  • Press ? to open the shortcuts panel on the right. It lists the most useful keys for where you are. ? again closes it.
  • Press Ctrl+P or : to open the command palette, Go to Command. It lists every command with its keys, including the few that have none. Type wrap and press Enter to run one.
  • Press g ? (or F1) for the Keymap, every key on one sheet. Esc closes it.
  • Press Ctrl+\ for the context menu of the focused line.
  • Read the Reference. It covers every feature, key and setting, including what this tutorial skipped, such as selection, copy and paste and Quick Add.

When you’re ready, start your own: tpt ~/notes.taskpaper creates the file when you first add something.

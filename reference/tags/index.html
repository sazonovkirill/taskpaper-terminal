Tags, dates and done

On this page

  • Done
  • Dates
  • Colors
  • Star, flag and bookmark
  • Edit Node

TaskPaper stores a block’s metadata as tags on its line: @done(2026-10-11), @due(2026-10-14), @green. tpt never shows tags in the outline and never lets you type one into a block’s text. Commands set and clear them, and their effects show instead: a done block is struck through, a date is a chip, a color tints the row. The one place to see and type any tag is the Edit Node dialog.

Typing @ at the start of a word, while editing, does nothing but say “Tags are set in Edit Node (e)” in the status line. Tags tpt doesn’t read are kept as they are, hidden like the rest, and listed in Edit Node.

Every command below acts on the selected blocks, or the focused one, as one step to undo. Where a command adds or removes a tag, it adds it to every block that lacks it, and removes it only when every block has it.

Done🔗

x marks a block done, adding @done with today’s date. On blocks that are all done already, it removes @done. With the kitty protocol, Ctrl+Enter does the same.

Any block can be done, not only tasks. A done block keeps its type, and is dimmed and struck through; a done task’s - becomes ✔. Everything inside a done block, at any depth, is dimmed too, but not struck through, since only the done block carries @done.

There is no archive. An Archive: project is an ordinary project.

Showing completed blocks🔗

gc hides the completed blocks in the focused pane, each with everything inside it, and shows them again. Each pane has its own setting, which starts on showing them and is saved with the pane layout. A new pane takes the setting of the pane it opened from.

Dates🔗

A block can have a start date (@start) and a due date (@due). Dates are days, written YYYY-MM-DD in the file, with no time.

Date chips🔗

Dates show as chips at the right end of the block’s first row, the start date before the due date. A start chip is green, a due chip red. Each names the date by how far it is from today:

ChipDate
today, tomorrow, yesterdaythose days
Tue2 to 6 days ahead
next Tue7 to 13 days ahead
in 15 daysfurther ahead
3 days agofurther back

A due date before today is overdue: its chip gets its own icon and is bold and reversed, unless the block is done or inside a done block. Chips follow the date: at midnight they change by themselves. A tag whose value is not a date shows no chip, and the block being edited shows none.

Setting dates🔗

KeyDoes

Moving a date a day works from today when the block has none, so ] on an undated block starts it tomorrow. Clear Start Date and Clear Due Date have no key: run them from Go to Command, the context menu or the edit-mode command menu, or empty the date prompt.

The date prompt🔗

ms and md open a prompt in a panel above the status line, titled with the date it sets, and dim the rest of the screen. It opens with the block’s current date typed and selected, so typing replaces it and Enter keeps it. Below the text it previews the date the text means, or says why it is not a date, in which case Enter does nothing. Empty text removes the date.

Date grammar🔗

The date prompt, the Edit Node dialog’s date rows and Quick Add all read dates the same way. Case doesn’t matter, and every form is relative to today’s local date:

TypeMeans

10-14, 10/14that day this year, or next year once it has passed, for a due date
today, tomorrow, yesterdaythose days
fri, friday, this frithe next Friday after today
next frithe Friday 7 to 13 days ahead, the one the chip calls next Fri
last frithe most recent Friday before today
this week, next month, last yearthe first day of that week, month or year; weeks start on Monday
weekend, this weekendthe coming Saturday, or today on a Saturday

Since there are no times, m means months, not minutes as in TaskPaper. Dates run from 0000-01-01 to 9999-12-31.

Colors🔗

A block can have one color, which tints its row’s background with a very dim shade from its marker to the pane’s right edge. Text colors stay as they are. The colors, in order, are red, yellow, green and blue, numbered 1 to 4.

  • C removes the color.
  • mc opens the color picker, with each color’s number. Type a number to choose at once, or type a name to filter.

Cycle Color, in Go to Command, steps the focused block’s color through none, red, yellow, green, blue, and back to none; selected blocks all get the same next color.

Setting a color removes any other color tag. @orange and @violet, colors in earlier versions, are kept in the file as ordinary tags. The Colors view lists every colored block, grouped by color.

Star, flag and bookmark🔗

  • s stars a block, shown as a star after its text. Starred blocks have their own view, and the Today view lists them too, unless you turn that off.
  • ! flags a block, shown as a red flag after its text. There is one flag, and it is red. Flagged blocks have their own view.
  • b bookmarks a block, shown as a bookmark icon after its text, and lists it under Bookmarks in the Navigator. The status line says “Bookmarked” or “Bookmark removed”.

The flag, star and bookmark come in that order, each a space after the text. They are hidden while the block is edited.

Edit Node🔗

e opens the Edit Node dialog on the focused block, the zoom title included, also while blocks are selected and in the special views. Edit Node in the edit-mode command menu opens it on the block being edited, and editing resumes when it closes. It shows every property of the block, one row each, and changes any of them:

RowShowsChange it with
TextThe block’s text, as edit mode edits it, without a project’s :Typing. An @ that would start a tag is not typed: tags go in the Tags rows.
TypeProject, Task or NoteSpace or → for the next of task, note and project, ← the previous, or p, t, n
DoneNot done, or Done and its dateSpace or x
ParentThe path to the block’s parent, or HomeSpace or typing opens a finder over the blocks it can move under, as Move to… lists them
Start, DueThe date, such as Thu 8 Oct 2026 · Today, or NoneSpace opens a field with the date; typing opens it empty. ←/→ move the date a day. Backspace or Delete removes it.
Starred, FlaggedWhether the block has @star or @flagSpace, or s and !
TagsEvery other tag, one per row, as @name or @name(value). Tags tpt doesn’t read are marked “unsupported”.Space opens a field holding the tag; typing opens it empty. Backspace or Delete removes the tag.
+ Add tagThe row after the tagsTyping a tag here adds it. A name the block already has changes that tag.
HiddenThe hidden lines under the block, each with its tags and line countNothing: the focus skips it

Sections and dividers show as notes in the Type row; a section’s @section is among its tags. In a tag field, a name and a value in parentheses, such as context(phone), sets a value. A leading @ is dropped. id, text, type and hidden can’t be tag names here: TaskPaper reserves the first three, and @hidden marks hidden lines.

Enter closes the dialog and applies every change as one step to undo; Esc closes it and changes nothing. While a field or the parent finder is open, Enter accepts it and Esc leaves it, and the dialog stays open. The last line of the dialog names the keys for the focused row. If the file is reloaded from disk while the dialog is open, it closes without changing anything.

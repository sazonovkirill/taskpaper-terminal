# Reference

Research snapshots of the systems taskpaper-terminal is compatible with or modeled on, gathered on 2026-10-04 from the official sources linked in each file. They describe other products, not our decisions; decisions live in [../requirements.md](../requirements.md) and [../specs/](../specs/README.md).

| File | Contents |
|---|---|
| [taskpaper.md](taskpaper.md) | TaskPaper file format, exact parsing rules, tags, query language, dates, saved searches, archive, editor behavior and edge cases. Sources: [guide.taskpaper.com](https://guide.taskpaper.com/) and the reference parser. |
| [workflowy.md](workflowy.md) | Workflowy's current features, search operators and full keyboard shortcuts, each tagged as portable to a terminal or GUI/cloud only. Source: [workflowy.com/help](https://workflowy.com/help/). |
| [feature-mapping.md](feature-mapping.md) | How each Workflowy feature maps onto the TaskPaper format. |
| [themes.md](themes.md) | The thirteen built-in truecolor themes (FR-UI-08): origin, license, palette hex values mapped to UI roles, and the Star Trek TNG adaptation's research. Sources linked in the file. |
| [tui-animation.md](tui-animation.md) | What terminal UIs can animate, tachyonfx, synchronized output, how other TUIs use animation, and the costs. Sources linked in the file. |

Markers used: **(inferred)** = our reasoning, not stated by the source; **(unverified)** = could not be confirmed in an official source.

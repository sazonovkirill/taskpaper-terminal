Every key of navigate and edit mode, with the defaults the app ships. Rebound keys are not shown here; the `?` panel in the app shows yours. Keys marked <sup class="ref-k">K</sup> need the [kitty keyboard protocol](@/reference/modes.md#classic-and-kitty-keys), and each has a key beside it that works everywhere. Print this page for a sheet to keep next to the keyboard.

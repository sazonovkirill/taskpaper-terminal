This tutorial takes about fifteen minutes. It starts with why tpt keeps your outline in a plain TaskPaper file, and why one endless outline beats a pile of lists. Then it puts you at the keyboard: you open a sample file and learn the app one chapter at a time, from moving around to dates, notes and split panes.

Each chapter builds on the one before, so read them in order the first time. Every chapter tells you which keys to press and what you should see. It does not try to cover everything; the [Reference](@/reference/_index.md) has the rest.

You need `tpt` installed:

```sh
cargo install --git https://github.com/sazonovkirill/taskpaper-terminal
```

Then download the sample file, [tutorial.taskpaper](/tutorial/tutorial.taskpaper), and put it somewhere you can find it. It holds a short trip plan, some chores and a work project, and every chapter uses it.
